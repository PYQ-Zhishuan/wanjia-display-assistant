# 门店美术陈列助手

选商品外形，拖动大小，选择或跳过场地，再按图试摆。

- 生鲜、包装商品两类，共 12 个参考外形。
- 8 种摆法，按商品外形筛选；每组放同款，整组重复。
- 可选普通重复、左右镜像、四向呼应，查看单组或整体的正面和俯视图。
- 可保存与读取方案；照片仅在本机作对照，不上传、不自动识别。

## 使用

网页入口为 `index.html`。离线使用请下载 [offline.html](offline.html)，保存后双击打开，无需安装。

## 发布

将本目录文件放在 GitHub 仓库根目录，在 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)，保存后等待发布。

## 文件

- `index.html`：网页入口
- `simple.css`：界面样式
- `templates.js`：商品基底、摆法与空间估算
- `simple.js`：交互及图示
- `offline.html`：包含样式与脚本的单文件离线版

这是用于试摆和演示的原型。模板尺寸为公开实例或示意估值，不是行业统一尺寸。空间估算与叠放效果须结合实物及门店现行要求确认；尚未开展门店实测。不连接库存、价格或订货系统，也不调用 AI 接口。
